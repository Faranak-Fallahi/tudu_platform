# Tudu Platform

> 🚧 **This project is currently under active development.**

**Tudu Platform** is a personal productivity and planning platform designed to help users organize tasks, habits, goals, and daily activities in one place.

The project is being developed with a **Django REST Framework backend** and a **Next.js frontend**, with the main development focus on backend architecture, API design, authentication, data modeling, and business logic.

## 🧩 Current Features

### 🔐 Authentication & Accounts

* Custom User model
* User registration API
* Token-based authentication
* Secure logout with token blacklisting
* User profile API

### ✅ Task Management

* Task model and relationships
* CRUD REST APIs
* User-based task ownership
* API tests for task functionality

### 🔄 Habit Management

* Habit model
* Habit Log
* REST API endpoints
* Ownership validation
* API tests

### 🎯 Goal Management

* Goal model
* Django Admin integration
* Initial foundation for the goal management system

### 🖥️ Frontend

* Next.js
* React
* TypeScript
* Component-based architecture
* UI development in progress
* Frontend–backend integration in progress
