# Tudu Platform

> 🚧 **این پروژه در حال توسعه فعال است.**

**Tudu Platform** یک پلتفرم برنامه‌ریزی و مدیریت بهره‌وری شخصی است که با هدف مدیریت یکپارچه‌ی کارها، عادت‌ها، اهداف و فعالیت‌های روزانه در حال توسعه است.

این پروژه با استفاده از **Django REST Framework** در Backend و **Next.js** در Frontend توسعه داده می‌شود و تمرکز اصلی توسعه روی معماری Backend، طراحی API، احراز هویت، مدل‌سازی داده‌ها و پیاده‌سازی منطق کسب‌وکار است.

## 🧩 قابلیت‌های فعلی

### 🔐 احراز هویت و حساب کاربری

* Custom User Model
* API ثبت‌نام کاربر
* احراز هویت مبتنی بر Token
* خروج امن با Token Blacklist
* API پروفایل کاربر

### ✅ مدیریت کارها

* مدل Task و ارتباطات مربوط به آن
* APIهای CRUD
* مدیریت مالکیت Task بر اساس کاربر
* تست‌های API مربوط به Task

### 🔄 مدیریت عادت‌ها

* مدل Habit
* Habit Log
* APIهای مربوط به Habit
* بررسی مالکیت داده‌ها
* تست‌های API

### 🎯 مدیریت اهداف

* مدل Goal
* اتصال به Django Admin
* ایجاد زیرساخت اولیه سیستم مدیریت اهداف

### 🖥️ Frontend

* Next.js
* React
* TypeScript
* معماری مبتنی بر Component
* توسعه رابط کاربری در حال انجام
* اتصال Frontend و Backend در حال انجام

## 🤖 توسعه با کمک هوش مصنوعی

ابزارهای هوش مصنوعی و **AI Coding Agents** بخشی از روند توسعه این پروژه هستند.

بخش Frontend با کمک **OpenCode** در حال توسعه است و از Agentهای هوش مصنوعی برای مواردی مانند:

* پیاده‌سازی کد
* Debugging
* بررسی و بازبینی کد
* Refactoring
* بررسی و ارزیابی راهکارهای فنی

استفاده می‌شود.

تخصص اصلی من **توسعه Backend با Python و Django** است و از ابزارهای هوش مصنوعی به‌عنوان دستیار توسعه برای افزایش بهره‌وری و بهبود روند پیاده‌سازی استفاده می‌کنم.

## 🧪 تست

است.
